My Day: Privacy Policy

Last updated: October 13, 2026

My Day is a personal, single-user application. It is used only by its developer, to summarize the developer's own Gmail and Google Calendar. It is not distributed to or used by other people.

What the app accesses

  • Gmail message metadata (sender, subject, date, labels) and, for some bank or payment notices, the message text needed to show an amount and merchant.
  • Google Calendar events for the current day, if calendar access is granted.
  • If label or trash access is granted, the app can add labels to messages or move messages to Trash, only as the owner configures or requests.

How the data is used and stored

  • All processing happens on the owner's own computer.
  • Google sign-in tokens and a local cache of message metadata are stored on that computer only.
  • Summaries are written to files on the same computer.

Sharing

The app does not sell, share, transfer or publish Google user data, and does not send it to any third party or advertising service. It does not use Google user data to train AI or machine-learning models.

Retention and deletion

The owner can delete the local cache, tokens and summaries at any time, and can revoke the app's access at myaccount.google.com/permissions.

Google API Services User Data Policy

My Day's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions: open an issue at github.com/igrapp/myday-privacy.
